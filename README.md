# ROBOT-AGRICOLA-S.A.S
Robot Agrícola SAS desarrolla un robot automatizado para la siembra de maíz, utilizando sensores, actuadores y software avanzado para optimizar el proceso agrícola. Está diseñado para apoyar a pequeños agricultores de la zona rural del municipio de Zipaquirá, reduciendo costos y mejorando la productividad del cultivo.
